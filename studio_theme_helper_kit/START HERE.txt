STUDIO THEME - NATIVE HELPER (optional)
=======================================

What it adds
  * Themes Studio's native Qt parts: panel tabs + title bars, menus, status
    bar, and the classic Properties panel. It uses your selected theme's colors.
  * Qt tab > Scan / per-widget colors.
  * Images tab > Browse opens straight in the images folder and copies your
    image there, so it survives restarts.
  * (Optional) fixes RML's "critical error" popup when you drag/resize panels.

Everything else in the mod works without it.


EASY WAY - GitHub builds it for you (no installs, ~15 minutes, free)
--------------------------------------------------------------------
1. Go to github.com and sign in (make a free account if needed).
2. Top right "+"  >  "New repository". Any name, e.g. studio-theme-helper.
   Public or Private both work. Click "Create repository".
3. On the new repo page click "uploading an existing file".
4. Open THIS folder (studio_theme_helper_kit) in File Explorer, select
   EVERYTHING inside it (Ctrl+A) - including the .github folder - and drag it
   onto the GitHub page. Click "Commit changes".
     * Don't see a .github folder? In File Explorer: View > Show > Hidden items.
     * If GitHub didn't take the .github folder: on the repo page click
       "Add file" > "Create new file", name it
           .github/workflows/build.yml
       paste the contents of .github\workflows\build.yml, commit.
5. Click the "Actions" tab. A run called "Build Studio Theme helper" starts by
   itself (if Actions asks you to enable workflows, click the green button,
   then "Run workflow").
6. Wait for the green check (10-20 min). Click the run, scroll to
   "Artifacts", download "studio-theme-helper".
7. Close Studio. Unzip it. Copy the "RobloxModLoader" folder inside on top of
       C:\Users\<you>\AppData\Local\Roblox\Versions\version-xxxx\RobloxModLoader
   and say Yes to replace.
8. Start Studio. Theme Editor > Qt tab should say "OK - native helper: applied".

Your RML version is set to 17589c0 (from your log). If you update RML later,
re-run the workflow: Actions > Build Studio Theme helper > Run workflow, and
type the new version from the first line of your RML log.


MANUAL WAY (if you have Visual Studio 2022 with C++)
----------------------------------------------------
    git clone https://github.com/revolutionxk/roblox-modloader.git
    cd roblox-modloader
    git checkout 17589c0
    (copy the studio_theme_qt folder into examples\)
    git apply path\to\rml_crash_dumper_fix.patch        (optional)
    cmake -B build -G "Visual Studio 17 2022"
    cmake --build build --config Release --target studio_theme_qt roblox_modloader
Then copy studio_theme_qt.dll into  RobloxModLoader\mods\studio_theme\native\
(and roblox_modloader.dll over the old one if you applied the fix).
